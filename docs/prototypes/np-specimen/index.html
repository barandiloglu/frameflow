This catalogue is a portfolio specimen for Northern Pathways Immigration Consulting, prepared by FrameFlow Studio in Toronto, MMXXVI.

Set in Montserrat by Julieta Ulanovsky — a contemporary geometric sans drawn in Buenos Aires — in weights 300, 400, 500, 600, 700, 800, 900, with a single italic at 500. Inks: charcoal #2C2B2B, paper #FFFFFF, off-white #F9F9F9, and a single saturated accent — maple red, #B92025.

The brand holds itself to one typeface and four colours. Within that lock, an entire range.
