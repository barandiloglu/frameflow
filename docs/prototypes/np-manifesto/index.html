D / 04 / Declaration 02 The Calculator · CRS / FSWP

02.   Declaration / The Web Application

We charge transparently.

A pair of regulatory-grade calculators in two languages. The CRS estimator covers IRCC’s 2025 grid — including the removal of arranged-employment points. The FSWP eligibility checker is a binary gate at 67/100. Each session finishes on a one-click PDF the principal can sign.

Pricing is listed on the fees page. Up front. No hidden lines, no surprises.
