# Big Bears V2 — Quiet Catalog

Standalone HTML preview at `index.html`. Open directly in any browser.

## Concept

Opposite extreme of the Mascot prototype. The page is treated like an exhibition catalog or art-book monograph: lots of cream/white space, tiny mono labels, strict grid, deliverables presented as numbered plates (Plate I, II, III…).

Yellow appears only as a hairline rule under captions. The work is the work; the page steps aside.

Tone: refined, archival, museum. Cormorant Garamond italic for body, Inter for sans, Lilita One reserved for the actual brand specimen.

## Sections

1. **Header** — back link · "FrameFlow · Toronto · 2024" · No. 005
2. **Title page** — institutional-style metadata grid (Project, Client, City, Year, Disciplines), giant italic Cormorant title, the logo as a single object on the right
3. **Part I — Essay** — three-paragraph text block, italic accents, small max-width
4. **Part II — Identity** — three plates:
   - Plate I · Primary mark (logo on a paper-tone frame)
   - Plate II · Four-color palette (3:4 swatches with named hex codes)
   - Plate III · Type system (Lilita One + Inter specimen)
5. **Part III — Photography** — Plates IV through XV in a strict 4-column grid, each captioned with its plate number
6. **Part IV — Menu** — Plates XVI–XVIII as a triptych
7. **Part V — Wrapper** — Plate XIX, full-bleed image with right-aligned spec list
8. **Colophon** — set-in-Cormorant credit, CTA

## Tone

Refined, restrained, archival. Reads like a Vignelli book or a Lars Müller monograph. The brand assets are *objects*, presented with neutral curatorial framing — yellow used sparingly only as a structural hairline.
