# Big Bears V2 — Photo Essay (Image-Led)

Standalone HTML preview at `index.html`. Open directly in any browser.

## Concept

Photos do the heavy lifting. Full-bleed images become section dividers, brand info layers between them. Reads like a food magazine spread or a Vimeo Staff Pick story page.

Stays on a dark Ink page (vs. Editorial's Cream) so the photos pop. Yellow is reserved for accents — chapter labels, italic emphasis on headlines, the final CTA.

## Sections

1. **Top rail** — overlaid on the cover photo
2. **Cover** — full-bleed hero photo (CU. Bowl — Pulled) with the wordmark dropped on top
3. **Chapter 01 — The brief** — narrative paragraph with sticky chapter label
4. **Photo break** — full-bleed Toppings Bar
5. **Photo pair** — Counter Service + Build Scoop side-by-side
6. **Identity strip** — palette + type on a Cream stripe (only break in the Ink flow)
7. **Mark** — logo overlaid on a kitchen-pass photo, brand-tinted
8. **Photo break** — full-bleed Takeout Sidewalk
9. **Contact sheet** — 6-col × 2-row grid of all 12 photos
10. **Menu** — 3 spreads stacked at slight rotations like printed copies
11. **Wrapper** — full-bleed pattern + spec column
12. **End** — credit, CTA on Ink

## Tone

More contemplative, food-magazine, photographer's portfolio. Less "studio reel" theatrics — chapters instead of scenes.
