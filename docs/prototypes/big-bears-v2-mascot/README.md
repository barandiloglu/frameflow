# Big Bears V2 — Maximalist Mascot

Standalone HTML preview at `index.html`. Open directly in any browser.

## Concept

Lean fully into Big Bears' personality. Bear icon recurs everywhere. Marquee tickers run between sections. Sticker-style badges, hand-drawn captions, drop-shadow type. Loud yellow + red dominate; cream is the only quiet moment.

Reads like the brand's actual website, not a portfolio piece. Tonally maximalist, fun, conversational.

## Sections

1. **Top rail** — yellow with red badge
2. **Marquee ticker** — `BIG BEARS · BAKED POTATO · LOADED BY BEARS · EST. 2024…`
3. **Hero** — wordmark with tri-layer drop shadow, bouncing bear logo, hand-drawn underline on `Bears.`
4. **Ingredient marquee** — `MEAT · POTATO · TOFU · TOMATO…`
5. **Intro** — letter-from-the-bear feel, mini wiggling bear, dotted decorations
6. **Identity stickers** — palette as 4 rotated circular stickers, type specimen as a cream banner with a red drop shadow
7. **Price marquee** — `SMALL $11.99 · BEAR SIZE $17.99…`
8. **Mark zone** — red backdrop with starfield pattern, three bears at different scales/rotations
9. **Photos** — horizontal scroll-snap row, each frame in a thick black border with red drop shadow
10. **Menu pinboard** — 3 spreads "pinned" to the orange wall with red push-pins, slight rotations
11. **Wrapper** — full-bleed pattern, then yellow info strip with hand-drawn callouts
12. **End** — red CTA with hand-drawn lead-in, big yellow button with offset shadow
13. **Footer ticker** — `FRAMEFLOW · BIG BEARS · 2024…`

## Tone

Anarchic, fun, food-truck-meets-skateboard-magazine. The whole page is yellow + red + black. Every section feels like a sticker, a poster, a marquee.
