02 · FSWP Eligibility · Six Selection Factors

Pass/fail at 67 of 100, with the math shown.

Federal Skilled Worker Programme eligibility is a binary gate at 67/100. We built the checker that gets clients there, line by line: age, education, language, work experience, arranged employment, adaptability.

The result is a single verdict — eligible or not — backed by a printable PDF with every factor itemised. Counsel can take it straight into a consult.
