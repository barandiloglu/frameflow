# Brand Showcase Prototype

A standalone HTML preview of how a client's brand could be showcased on its `/portfolio/[slug]` subpage. Open `index.html` directly in a browser — no build, no dev server, no React.

## What this explores

A "Brand Scene" — the client's actual palette + typefaces taking over a section of their subpage as if it were a cinema title card, framed by FrameFlow chrome. Three stacked blocks:

1. **The scene** — full-bleed in the client's primary color, wordmark in their display typeface, tagline in their body typeface, FF mono labels and corner brackets wrapping it.
2. **The palette** — a perforated filmstrip of the client's colors, each block labeled in the client's display face.
3. **The type** — a magazine-style specimen sheet showing display + body samples.

The example uses **Big Bears Baked Potato** with illustrative brand data (Toast / Char / Cream / Ember palette; DM Serif Display + Inter type stack). Real brand data goes in once we have it.

## Why this approach (vs. the first attempt)

The first attempt was a small bordered "Brand notes" card with tiny swatches and font names rendered as plain text. It read like a Figma config tile — utilitarian, not editorial. This version treats the brand as an **exhibit**: bold, full-width, using the client's actual visual language so you _see_ what they look like, not what they're labeled.
