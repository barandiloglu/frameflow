# Big Bears V2 — Editorial (Brand-Led)

Standalone HTML preview at `index.html`. Open directly in any browser — uses real Big Bears assets via relative paths to `public/portfolio/big-bears/`.

## Concept

Drop the FF "Frame · 0X — The Y" chrome on every section. Dress the **page** in Big Bears: yellow becomes the dominant color, bear logo recurs, brand fonts (Lilita One + Nunito) drive headlines instead of FF mono.

Each section has a bespoke layout — no template repeating. Reads more like a Pentagram or Collins case study than a film-studio reel.

## Sections

1. **Top rail** — minimal back link + studio mark
2. **Hero** — full-bleed Yellow with the wordmark and the bear logo featured at scale
3. **Intro** — wide editorial paragraph on Cream
4. **Identity** — palette as 4 colored bands + type specimen on Ink
5. **Mark** — logo on Yellow with usage notes on the side
6. **Photos** — magazine-style asymmetric grid (12 frames)
7. **Menu** — 3 pages displayed as a triptych on Burnt Orange
8. **Wrapper** — full-bleed pattern + spec column on Ink
9. **End** — credit, return link, project CTA
