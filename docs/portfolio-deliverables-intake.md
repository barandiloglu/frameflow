# Portfolio Deliverables Intake

For each client, list the **actual artifacts** we have on hand and where they live. Goal: feed this into the portfolio rebuild so each client subpage shows their real work, not placeholders.

## What to fill in per client

For every checked service, note:
- **Where the asset lives** (Drive folder, Dropbox, Notion page, live URL, internal repo, etc.)
- **Status:** ✅ public · 🔒 NDA / private · ⚠️ mockup-only / not delivered
- **One-line note** if anything is unusual (e.g., "campaign live Mar–May 2026", "v2 in progress", "client took it down")

## Per-service quick reference — what we usually need

| Service | What to gather |
|---|---|
| **Logo** | Final SVG (and PNG fallbacks). Mono / knockout variants if produced. |
| **Branding** | Brand guide PDF, color palette (hex), typeface names, voice/tone if documented. |
| **Design** | Whatever the design output was (poster, packaging, collateral) — links to artwork. |
| **Photography** | Folder of finals (web-resolution OK), shoot date, location. |
| **Videography** | YouTube / Vimeo / direct file link, runtime, hero stills. |
| **Social Media** | Platforms (IG / TikTok / FB), sample posts (3–6 hero pieces), campaign hashtag, run dates. |
| **Website Design** | Live URL, hero screenshots, before/after if available. |
| **Web Application** | Live URL, screenshots of key flows, demo credentials (if shareable). |
| **App** | App Store / Play Store link, screenshots, key flows. |
| **SEO** | Target keywords, before/after rankings or traffic, time period. |
| **Ad Management** | Platform (Meta / Google / TikTok), creative samples, key result (CPA, ROAS, etc., if shareable), campaign dates. |
